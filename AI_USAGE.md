# Использование AI

Работа выполнена 20 октября 2026 года в Codex desktop в одном чате. AI использовался для реализации и проверки MVP по заданию пользователя. Отдельные агенты не запускались.

## Реально использованные инструменты

| Инструмент | Что сделано |
| --- | --- |
| Codex | Выбор минимального стека, проектирование версии формы и снимка отклика, генерация и редактирование серверного и клиентского кода, тестов и документации. |
| `functions.exec`, `exec_command`, PowerShell, Node.js, npm, Git | Осмотр среды, создание проекта, синтаксическая проверка, установка, запуск/остановка, интеграционные тесты, чистая копия, локальные коммиты. |
| `apply_patch` | Создание и правки исходных файлов. |
| `mcp__cua_repl` | Реальный браузер: создание, редактирование, перестановка и удаление вопросов, публикация, валидация, сбой сети, восстановление черновика, отправка, просмотр отклика, визуальная проверка адаптивности и подтверждения. |
| Подключение GitHub и локальный Git | Проверка публичности репозитория и первоначального отсутствия прав записи у подключения. После настройки локальной авторизации пользователем выполнен `git push` с публикацией проекта. Подробности — в журнале. |
| Навык Sites | Прочитаны инструкции по локальному предпросмотру и интерфейсу. По прямому требованию пользователя облачный хостинг и шаблон Sites не использовались. |
| Навык Computer Use | Прочитана вводная инструкция; нативная автоматизация Windows не применялась. Браузер проверялся через CUA. |

Генерация изображений, внешние API в приложении, облачные БД, платные сервисы и отдельные СУБД не применялись. Подключения среды разработки не являются зависимостями готового приложения.

## Что проверено и исправлено

- `node --check server.js`, `node --check public/app.js`.
- `npm install`, `npm start` и запуск на `http://localhost:3000`.
- `npm test`: 10 пройденных тестов с реальными HTTP-запросами, отдельным JSON-файлом и перезапуском сервера. Включены конкурентное сохранение, дедупликация отправки, старые версии, обязательность, email, допустимые варианты и лимиты.
- При первом запуске в Windows `fsync` на дескрипторе, открытом только для чтения, вернул `EPERM`. Изменён режим открытия временного файла на `r+`, после чего сервер и запись заработали.
- При ревью обнаружен риск проверки `revision` по объекту, прочитанному до асинхронного чтения тела запроса. Добавлено повторное чтение актуальной формы перед проверкой; конкурентный тест подтверждает один успех и один 409.
- Исправлено восстановление состояния выключенных кнопок во время сохранения, чтобы крайние стрелки порядка оставались недоступными.
- В браузере остановлен реальный сервер перед отправкой; показана ошибка, ответы не очищены. После запуска сервера и перезагрузки вкладки восстановлены все четыре ответа; повторная отправка завершилась успешно.
- Проверены мобильная форма, подтверждение и админка; ширина содержимого не превышает ширину viewport. После удаления вопроса и новой публикации старый отклик по-прежнему содержит удалённый вопрос и его ответ.

Подробности и границы проверок — [docs/VERIFICATION.md](docs/VERIFICATION.md).
